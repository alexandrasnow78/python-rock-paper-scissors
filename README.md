
# Rock-Paper-Scissors Game

An interactive Rock-Paper-Scissors game developed in Python. Players compete against the computer in multiple rounds, with the program keeping track of each player's score.

## Features

- Play Rock-Paper-Scissors against the computer
- Generate random computer choices
- Determine the winner of each round
- Track player and computer scores
- Play multiple rounds without restarting the program
- Accept user input regardless of capitalization
- Handle invalid input with an error message
- Exit the game by typing "quit"

## Technologies Used

- Python
- Python's built-in `random` module

## How to Run

1. Make sure Python is installed on your computer.
2. Download the Python file from this repository.
3. Run the program using Python.
4. Enter `rock`, `paper`, or `scissors` when prompted.
5. The computer will randomly select its move.
6. The program will announce the winner and display the updated scores.
7. Continue playing or type `quit` to exit.
